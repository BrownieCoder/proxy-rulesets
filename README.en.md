# Proxy Rulesets

Public routing rules for AI, Apple, gaming, media and network services.

**Choose a service, read its scope, and copy its rule URL—all in this GitHub repository.**

[Service directory](README.md#服务目录) · [Advanced reference](docs/advanced.md) · [Maintainer guide](docs/maintainer/README.md)

Each service page includes a copyable raw URL, a link to the actual rule file, its existing policy, scope notes and source attribution. Copying a URL or downloading a file does not change your configuration. These files are rules, not node subscriptions or complete configurations.

Preserve security rules first, international gaming before China gaming, and specific services before broader matches. Siri AI rules only choose network routes; they do not change device, account, region or language eligibility.
