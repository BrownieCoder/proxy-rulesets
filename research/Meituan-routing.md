# 美团公开主机分流依据

## 目标与边界

为七个经官方公开页面核实的美团主机提供 `🍜 美团` 独立策略，默认 `DIRECT`，保留手动代理选择。它们原已由 ChinaMax 覆盖；本次增加独立控制与优先匹配，不宣称此前完全没有覆盖。

2026-11-14 读取美团官网、外卖入口与移动入口的公开 HTML，只提取公开主机名。没有登录或采集账户、订单、位置、支付信息。移动入口会跳转验证中心；没有绕过验证，也没有由验证页推断移动业务内容。

## 已接受精确主机

全部使用 `DOMAIN`；不扩展 `meituan.com`、`meituan.net`、`sankuai.com`、大众点评或共享 CDN 根域。

| 精确主机 | 官方来源 | 观察与用途 | 置信度与目标 |
| --- | --- | --- | --- |
| `www.meituan.com` | [美团官网](https://www.meituan.com/) | 官网入口 | 高；默认直连，可选代理 |
| `i.meituan.com` | 官网的消费入口链接及[移动入口](https://i.meituan.com/) | 官网引用的移动消费入口；直接访问时触发验证，未验证业务页内容 | 中高；默认直连，可选代理 |
| `waimai.meituan.com` | [美团外卖](https://waimai.meituan.com/) | 官方外卖网页入口 | 高；默认直连，可选代理 |
| `img.meituan.net` | 美团官网 HTML 的资源引用 | 官网图像与资源主机 | 高；仅该主机，可能跨美团业务 |
| `p0.meituan.net` | 美团官网 HTML 的资源引用 | 图像资源主机 | 高；仅该主机，可能跨美团业务 |
| `p1.meituan.net` | 美团外卖 HTML 的资源引用 | 图片资源主机 | 高；仅该主机，可能跨美团业务 |
| `s3plus.meituan.net` | 官网、外卖及移动入口 HTML 的资源引用 | 静态资源主机 | 高；仅该主机，可能服务多个美团业务 |

置信度描述的是公开页面使用或链接这些主机的证据，不是全部对象所有权、实时可用性或 App 全链路覆盖的保证。

## 保留原有边界

不纳入 `report.meituan.com`、`analytics.meituan.net` 等已有隐私拦截，也不加入 `lx`、`wreport` 追踪候选、测试环境或 `www.dpfile.com` 等点评共享资源。Privacy/Hijacking 继续优先，合法安全更新可以先于本组命中。

本组仅覆盖公开官网、消费/外卖入口及部分资源。没有验证原生 App 的订单、支付、定位、登录、外卖下单、图片全链路或 UDP。手动选代理只改变这七个主机；其他美团请求继续使用原有路由，可能混合直连与代理出口。资源主机上的其他美团业务请求也会受同一策略影响。

如果手动切到代理后出现登录或地区识别异常，可先恢复直连再排查；这只是条件性排错建议，不是已实测会发生异常或触发风控的结论。

验证采用公开规则快照做离线域名首条匹配模拟，覆盖精确范围、默认策略、前置安全、相似域名和其他服务的路由不变。真实 DNS、GeoIP、网络地区与设备行为仍需使用者自行核实。
