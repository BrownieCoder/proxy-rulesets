# 高德地图：独立出口策略与域名依据

## 决定

为六个已核实的高德官网、移动入口及公开地图接口主机提供 `🗺️ 高德地图` 独立策略，默认 `DIRECT`，保留手动代理选项。规则只使用精确 `DOMAIN`，不加入整个 `amap.com`、`autonavi.com` 或阿里巴巴、共享 CDN 的根域。

这六个主机当前都已被 ChinaMax 的 `amap.com` 后缀覆盖，命中 `🇨🇳 China-Global`。本次增加的是独立出口控制和优先级，不是此前完全没有覆盖。安全拦截和国际/中国游戏规则继续优先；本组位于通用 Apple、国际媒体、GeoIP 中国与 ChinaMax 之前。

## 已接受的精确主机

证据核实日期：2026-11-13。下列来源均为高德第一方网站或公开开发文档。

| 主机 | 来源 | 用途与目标 | 置信度与影响范围 |
| --- | --- | --- | --- |
| `maps.amap.com` | [高德在线地图](https://maps.amap.com/) | 地点搜索和路线规划网页；默认直连 | 高；仅该主机 |
| `ditu.amap.com` | [高德在线地图旧版入口](https://ditu.amap.com/) | 旧版在线地图和 App 导流入口；默认直连 | 高；仅该主机 |
| `mobile.amap.com` | [高德地图官方网站](https://mobile.amap.com/cn/index) | 高德地图 App 功能介绍与下载入口；默认直连 | 高；仅该主机 |
| `m.amap.com` | [高德地图手机版](https://m.amap.com/) | 官方移动地图入口；默认直连 | 高；仅该主机 |
| `webapi.amap.com` | [高德 AMapUI 官方文档](https://lbs.amap.com/api/amap-ui/intro/) | 文档使用该主机加载 JS 地图与 UI 组件；默认直连 | 高；也影响第三方网站或 App 中的高德地图集成 |

公开接口文档包含带 key 的调用示例；本记录只保存不含 key 的主机和公开文档地址，不保存或请求任何实际 API 凭据。

## 范围与验证限制

这是一组有证据支持的官网和接口基础主机规则，不是完整的原生 App 导航、定位、地图瓦片或打车规则。不能由公开文档推断原生 App 一定使用相同主机，也不承诺覆盖全部请求。未验证的其他域名继续走现有规则。

默认直连是可调整的出口建议，实际可用性取决于网络和服务。没有登录高德账户，没有采集位置、导航路线或私人流量，也未进行原生 App、DNS、GeoIP、UDP 或定位精度实测。

离线验证检查目标首次命中、安全规则优先、默认直连及代理选项、精确主机边界，以及相邻主机/其他服务在加入本组前后维持原出口。
