# 知乎独立分流依据

## 目标

为已核实的知乎网页、公开前端 API 配置与资源主机提供 `💡 知乎` 独立策略：默认 `DIRECT`，保留手动选择代理。
这 8 个主机在基线已经由 ChinaMax 覆盖；新增价值是独立控制和在宽泛规则前匹配，不是宣称此前没有覆盖。

手动把 `💡 知乎` 切换到代理时，仅上述 8 个主机改变出口；根域、`m.zhihu.com`、未列出的图片主机等仍沿用原有分流，可能继续通过 ChinaMax 直连。因此会出现同一服务使用不同出口的情况；本组不保证完整 App 覆盖或一致的出口 IP。

## 顺序与验证边界

安全拦截和游戏规则优先；知乎规则位于通用 Apple、影音、GeoIP CN 与 ChinaMax 之前。Privacy 或 Hijacking 合法命中时仍保留安全策略。

验证包含域名首匹配模拟、精确规则边界、默认出口和代理选项。`zhihuishu.com`、相似主机、目标的子域、其他资源主机及第三方服务不得被新增规则捕获。

本次没有读取私人配置、登录账户或 App 流量，没有实测登录、发布、视频播放、DNS、GeoIP 或 UDP。公开网页引用只能证明这些主机被官网使用，不保证知乎 App 所有功能或所有网络地区可用。
